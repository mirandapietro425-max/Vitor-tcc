# RastroPet

Site de rastreamento de animais perdidos, com painel de animais, mapa de localização demonstrativa, acesso Bluetooth e área preparada para integração futura com Arduino de maior alcance.

## Publicar na Vercel

1. Importe o repositório `mirandapietro425-max/Vitor-tcc` na Vercel.
2. Selecione a raiz do repositório como **Root Directory**.
3. Não é necessário configurar comando de build: esta versão já está compilada e pronta para servir como site estático.
4. Clique em **Deploy**.

O arquivo `vercel.json` mantém as rotas internas do aplicativo funcionando quando uma página é recarregada.

## Observação

As posições dos animais são demonstrativas nesta versão. A integração real com uma coleira GPS/Bluetooth ou com o Arduino depende do protocolo e do hardware que serão definidos.
